🇬🇧 English | 🇩🇪 Deutsch

## 🇬🇧 English

My first GitHub repository and a first step into Python, Git, and GitHub.

### About

This repository contains two small Python exercises created while learning the basics of programming:

* **`hello_github.py`** – a simple exercise using functions and the `main()` structure
* **`square_calculator.py`** – a simple program for calculating the square of a number

### Learning Goals

This repository was created to practice:

* Python basics
* Functions
* Variables and calculations
* Structuring simple Python programs
* Git and GitHub
* Creating and updating a repository

### How to Run

Python 3 is required.

For example:

```bash
python square_calculator.py
```

or:

```bash
python hello_github.py
```

### Background

This repository documents my first steps in Python and GitHub. My later projects build on these foundations and increasingly focus on data analysis, data visualization, and data science.
