
# First-REPO

My first GitHub repository created while learning Python and Git/GitHub.

## About

This project contains a simple Python program for calculating the square of a number.

It was created as an introductory exercise to practice:

* Python basics
* Functions and user input
* Basic input validation
* Git and GitHub workflow
* Creating and updating a repository

## How to Run

Make sure Python 3 is installed.

Run the program from the terminal:

```bash
python square_calculator.py
```

Enter a number when prompted, and the program will calculate its square.

## Example

```text
Enter a number: 5
The square of 5 is 25.
```
